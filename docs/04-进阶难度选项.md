> 版本 0.2 · 2026-10-15 · 根据头脑风暴线程整理

> 上位文档：[01-架构设计总览.md](01-架构设计总览.md) §6.8。本文是所有**可选进阶难度开关**的唯一清单；新增开关先登记在这里。品质细则见 [05-品质系统.md](05-品质系统.md)。

## 0. 总则

- 开关在新档开始时选择；也可通过**调试台**中途开启（品质的中途开启规则见 05 文档 §4）。
- 开关只影响真相层的规则，不改变必定内容的流程；关闭时相关系统退化为"永不出错"。
- 每项开关都应有对应的"买回来的方式"（技能、设备或员工），与总览 §1 设计支柱一致。
- 实现：`DifficultyFlags` 作为存档根节点的字典 `{flag_id: bool}`，规则通过 `Flags.is_on("...")` 读取；层级关系由 `FlagDef.parent` 表达，总开关 / 附属开关的联动在 `Flags.set()` 内统一处理，UI 不写规则。

## 1. 开关层级

```
quality（品质，总开关）
├── quality.mold        霉菌
├── quality.flatness    平整
├── quality.misweave    错织
└── quality.misdye      错染
manual_checkout         手动结账（独立）
employee_embezzlement   员工贪腐（独立）
wholesale_late_payment  批发拖欠付款（独立）
```

**总开关 / 附属开关规则**：
- 打开 `quality` ⇒ 四个附属开关全部打开。
- 可以逐个关闭附属开关，但**至少保留一个**；关到零个时 `quality` 自动关闭。
- 附属开关全关时，`quality` 不能打开（UI 灰显并提示）。
- 附属开关不能在 `quality` 关闭时单独打开。

## 2. 品质总开关 `quality`

- **效果**：围巾获得品质属性（`ScarfItem.quality`），四个维度由附属开关决定；厂商与物流公司出现隐藏的品质参数，并提供更多可选对象；新增【验货】【观察】【追溯】【拉平】等动作与退货 / 索赔流程。
- **关闭时**：所有围巾视为优质，`quality = null`，相关动作与 UI 不出现。
- **买回方式**：见 05 文档 §5。

### 2.1 霉菌 `quality.mold`
- 真 / 假。出现即报废、不可售。来源：厂商、运输、自家仓库湿度（连续累积）。
- 需【追溯】归责：厂商 → 退货；运输 → 索赔。与 `wholesale_late_payment` 联动：退款 / 赔付会被拖延。
- 买回：收货验货、除湿机、仓库与物流公司选择。
- （吸收了 v0.1 的"仓库受潮发霉"与"物流破损"的受潮部分。）

### 2.2 平整 `quality.flatness`
- 百分比。来源：倒地（03 文档）、运输颠簸、堆底长期挤压（离散 + 连续）。
- 【拉平】修复，恢复率与上限按材质（05 文档 §1.2）。低于阈值折价。
- 买回：抽取技能、平整台 / 熨烫机、员工代劳。
- （吸收了 v0.1 的"皱巴巴的货物"与"物流破损"的颠簸部分。）

### 2.3 错织 `quality.misweave`
- 真 / 假，**隐藏**，须【观察】发现。未发现售出后按常数概率被退还（扣信誉）。厂商问题，可退货。
- 买回：观察动作、观察类技能（待定）、员工验货。

### 2.4 错染 `quality.misdye`
- 真 / 假 + 区域大小 `area`。隐藏，区域越大越易被观察发现、也越易被退回。
- 退货率 `p_return = area^(1 − area^(1/e))`（曲线见 05 文档 §1.4）。厂商问题，可退货。
- 买回：同错织。

## 3. 独立开关

### 3.1 手动结账 `manual_checkout`
- **效果**：成交时玩家须用游戏内计算器逐项算出总价。算低了自己亏（善意客人会提醒）；算高了事后被追究，扣信誉。
- **触达系统**：结账 UI、`CustomerProfile.kindness`、信誉。
- **买回方式**：数学能手 Lv1（快速求和）、Lv4（单项总价）；员工代为结账。

### 3.2 员工贪腐 `employee_embezzlement`
- **效果**：被委托的员工依隐藏性格与薪资满意度，可能收回扣或偷货；账本与真相层出现差异。
- **触达系统**：ActionAPI 审计、`Employee.misconduct_log`、`Ledger` vs `TruthFinance`。
- **买回方式**：数学能手 Lv2 / Lv5（对账）、员工观察 Lv6、谈心。
- **附带开启**：处置动作【报警】（误报则玩家被拘留 7 天并罚款，见 01 §4.4）。

### 3.3 批发拖欠付款 `wholesale_late_payment`
- **效果**：批发客人可能拖欠账款，需催账。**同时**使厂商退款与物流赔付（05 文档 §3）按同一逻辑延期。
- **触达系统**：`CustomerProfile.credit`、应收账款、宏观经济 `wholesale_credit_risk`、退货 / 索赔账期。
- **买回方式**：客人观察、口才（催账）、拒绝赊账。
