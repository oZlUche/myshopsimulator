## 0. 定位

这份文档把客人从"经过 → 问价 → 议价"的粗状态机，细化成一条以**预期值**和**成交可能性 `P`** 为核心的完整流程，取代现有 `HaggleState` 里"客人出价逐轮向心理价靠拢"的模型。议价 UI 仍是混合式（自由输入价格 + 选项），但选项从"台词"变成**有数值作用的策略**。

一句话版：客人带着一组**想要什么**（预期值向量）来，摊上有接近的货才会开口；开口后双方的每一次互动都在改一个数 `P`（成交可能性，0 到 1 以上）；玩家用**策略**缩小货与预期的差距把 `P` 推高，用**报价**踩进浮动心理价，两条路都能成交；客人的**耐心是次数**，用完就走。整套流程的每一步都要查客人的**性格**，所以 §1 先把性格怎么建模说清楚。

## 1. 性格建模：独立变量还是向量（2026-10-21 拍板：方案 C）

### 1.1 这套流程用到的性格

| 性格 | 用在哪一步 | 现有字段 |
|---|---|---|
| 热闹偏好（喜欢人多 / 喜欢清净，连续值） | §3.1 停留 | 无 |
| 挑选速度 | §3.2 挑选 | 无 |
| 挑剔度（预期值容差、对策略的信服度、递错货的反应） | §3.2、§3.4、01 §6.4 | 无（口才 Lv4 的放宽是技能侧） |
| 预期值数量（想买几种） | §3.2、§3.5 | 无 |
| 主动 / 被动（自己报价还是问价） | §3.3 | 无 |
| 诚实 / 算计（开价离心理价多远；自取时付不付足） | §3.3、§3.6 | `haggle_strategy` 部分覆盖 |
| 耐心（**次数制**，标准 5–7 次） | §3.4 | `patience`（0–1 连续） |
| 脾气 / 语气（耐心归零时的反应） | §3.4 | 无 |
| 再逛倾向 | §3.5 | `intent`、`hesitation` |
| 自取 / 转身走 | §3.6 | 无 |
| 善意（算错账会不会提醒） | 手动结账 | `kindness` |
| 马虎（抽货出错） | 03 §5 | `careless` |
| 回购倾向 | 常客 | `loyalty_base` |
| 犹豫度 | 问价前的磨蹭 | `hesitation` |
| 预算 / 经济情况（**不是性格，是状态**） | 心理价、容差（待办） | `budget_mult` |

去掉非性格的预算，**十四个左右**。现在的 `CustomerProfile` 是方案 A 的雏形（七八个独立浮点），再往上加一倍字段就要碰到 A 的天花板，所以这里停下来选一次。

### 1.2 方案 A：每个行为一个独立浮点

就是现状的延伸：`crowd_pref`、`browse_speed`、`fastidious`、`initiative`、`candor`、`patience_n`、`temper`、`self_serve` …… 各自 0–1，生成时各自独立随机。

- **优点**：每个行为一个旋钮，调哪个改哪个，不会牵连别处；代码里查字段直白；【客人观察】要显示哪一项就读哪一项；加新机制加一个字段就行。
- **缺点**：(1) **人设不自洽**。十四个独立随机数会生成"主动开价却极度害羞、挑剔到容差为零又马虎到把货抽塌"的客人，玩家读不出"这是个什么人"，【客人观察】Lv4 显示的"性格"也就没有预测力。(2) **随机生成趋于平庸**。十四个高斯各自采样，绝大多数客人在每一项上都是中等，鲜明的人很少。(3) **平衡困难**。十四个维度的联合分布没人能凭感觉调，只能一个个调，而玩家感受到的是组合。(4) **字段只增不减**，每加一个机制就加一个字段，存档迁移次数跟着涨。

### 1.3 方案 B：一个完整性格向量，全部行为由公式推导

定义一个低维潜在向量（比如心理学的大五，或自定的 5–6 维），所有行为参数都是向量的函数：`patience_n = f(向量)`、`crowd_pref = g(向量)` …… 不单独存行为参数。

- **优点**：(1) 人设天然自洽：同一个"外向"同时决定了爱热闹、主动开价、耐心归零时会嘟囔，玩家看到一个表现就能预测其他。(2) 存档小、生成简单，原型（"精明大妈""腼腆学生"）就是向量空间里的几个点。(3) 【客人观察】揭示一个维度就等于揭示一组行为，技能更值钱。(4) **员工可以复用同一向量**（02 文档里员工的隐藏性格本来就是同类东西）。
- **缺点**：(1) 调一个行为必须改公式，而公式一动所有客人一起变，难以只调"耐心"不碰别的。(2) 总有行为与任何维度都不相关（比如挑选速度），硬塞进公式就是在编故事。(3) 调试时看到的是潜在值，要在脑子里过一遍映射才知道这位客人会做什么。(4) 维度一旦定下很难加：加一维等于重做所有映射。

### 1.4 方案 C（已采用）：少量潜在维度 + 派生行为参数（两层）

**取 B 的自洽和紧凑，保留 A 的可调与可读**：性格是一个 **5 维潜在向量**（真相层，隐藏），生成客人时**一次性**按一张映射表把它算成 §1.1 的全部行为参数，并给每个行为参数加少量独立噪声；之后代码只读派生参数，不再碰向量。

**潜在维度**（都是 0–1，按这个游戏的需要起名，不照搬心理学）：

| 维度 | 高 | 低 | 主要驱动 |
|---|---|---|---|
| **外向** `sociable` | 爱热闹、主动开价、耐心归零会嘟囔、更愿意再逛 | 喜欢清净、被动问价、默默走 | 热闹偏好、主动/被动、语气、再逛、自取 |
| **精算** `shrewd` | 开价远低于心理价、买多要优惠、识破吹嘘、自取可能少付 | 开价接近心理价、好说话 | 诚实/算计、δ、策略识破率、`haggle_strategy` |
| **从容** `composed` | 耐心次数多、挑得慢、等货等得久、不犹豫 | 急、看两眼就走、等不及 | 耐心、挑选速度、等待时间、犹豫 |
| **挑剔** `fastidious` | 容差小、预期值多、策略难说服、递错货反应大、在意品质 | 什么都行 | 容差、预期数量、策略成功率、品质敏感 |
| **随和** `agreeable` | 善意提醒算错账、好感权重 ρ 大、回购高、自取付足 | 冷淡、不提醒、回购低 | 善意、ρ、回购、语气 |

外加一个**不属于性格的动作参数** `careless`（马虎，抽货出错），因为它是手上功夫不是脾气，继续独立存。预算 / 经济情况、常客熟悉度（`visits`）、当天心情（每次来摊随机一个 −0.2..0.2 的偏移）都是**状态**，与性格分开。

**映射表示例**（放在 `data/personality_map.json`，调参不改代码）：

```
patience_n   = round(5 + 2·composed + 1·agreeable − 1·shrewd + N(0, 0.5))   → 夹到 3..9，标准 5–7（常数原为 4，实测分布集中在 5 偏低，2026-10-21 上调为 5；PR #14 后抽 2000 人实测均值 6.1，5–7 次占 93%）
crowd_pref   = 2·sociable − 1 + N(0, 0.15)                                    → −1..1
initiative   = 0.7·sociable + 0.3·shrewd + N(0, 0.1)
candor       = 1 − shrewd + N(0, 0.1)
tolerance    = 0.55 − 0.35·fastidious + N(0, 0.05)                           → 预期值容差
n_expect     = 1 + round(1.5·fastidious + 0.5·(1−composed) + N(0, 0.3))      → 1..3
browse_speed = 0.3 + 0.4·(1 − composed) + 0.3·(1 − fastidious)
temper       = sociable·(1 − agreeable)                                      → 归零时嘟囔的概率
self_serve   = 0.15 + 0.6·initiative − 0.2·agreeable                          → 等不到人自己拿的概率
hesitation   = 0.6·(1 − composed) + 0.2·fastidious
kindness     = agreeable；ρ、δ、loyalty_base 按 01 §4.3 公式换成用 agreeable / shrewd
```

**生成**：不是在 5 维空间里均匀撒点，而是从几个**原型**里按权重抽一个再加噪声（精明大妈、腼腆学生、爽快大哥、挑剔白领、闲逛老人……），原型权重可以按街区、时段、季节变。这正好承接 §3.1 的"保底"：保底客人就是在原型里挑一个与当下摊位最合拍的。

**存档**：常客存潜在向量 + 派生参数（派生好的不再变，保证"熟客还是那个人"）；过路客只存潜在向量 + 噪声种子，读档时重算（过路客本来活不过一旬，公式升级影响不到玩家记忆）。老存档迁移：用现有字段反推一个近似向量（`patience → composed`，`kindness → agreeable`，`haggle_strategy → shrewd`），其余维度按原型就近补。

**【客人观察】**：Lv4"性格"改为显示 **两到三个最突出的维度**的定性词（"精算、急"），比显示三个独立字段更能让玩家预测他下一步做什么；Lv2 耐心直接显示 `patience_n` 剩余次数。

**为什么它比 A、B 都好**：行为参数仍然一个一个存、一个一个读（A 的可读可调）；但它们来自同一个人设，不会出现矛盾组合（B 的自洽）；调参改映射表的一行，只影响一个行为（避开 B 的最大缺点）；加新机制时先问"它归哪个维度"，答不上来就像 `careless` 一样独立存（避开 B 的第四个缺点）；员工隐藏性格直接复用同一张表，02 文档的"员工性格隐藏、谈心揭示"不用另起一套。

**代价**：多一张映射表要维护；调参时要记得"改公式只影响新生成的客人，常客不变"；设计者得克制，不要为了每个新行为加一个新维度（五维是上限，加维度要走文档）。

### 1.5 结论（2026-10-21 用户拍板）

1. 采用**方案 C**。
2. 五个维度：外向、精算、从容、挑剔、随和，外加独立的马虎。映射表放 `data/personality_map.json`，§1.4 的公式为初值，调参改表不改代码。
3. 员工隐藏性格复用同一向量与映射表（按推荐执行，02 文档后续同步）。

### 1.6 实现值（PR #13）

- 映射表 `data/personality_map.json`，维度顺序 `[sociable, shrewd, composed, fastidious, agreeable]`，每维噪声 σ = 0.15。
- **原型**（权重 / 向量）：精明大妈 0.22 `[.7, .85, .5, .5, .4]`；腼腆学生 0.18 `[.2, .3, .4, .35, .65]`；爽快大哥 0.20 `[.8, .25, .45, .2, .75]`；挑剔白领 0.20 `[.4, .55, .3, .85, .35]`；闲逛老人 0.20 `[.45, .4, .85, .45, .7]`。
- 文档未给、实现补的派生公式：`intent = 0.35 + 0.3·sociable + 0.15·(1 − shrewd)`；`kindness = agreeable`；`loyalty_base = 0.1 + 0.45·agreeable`；`self_serve = 0.15 + 0.6·initiative − 0.2·agreeable`。
- `haggle_strategy` 阈值：`shrewd > 0.6` → 直接砍价；否则 `sociable > 0.55` → 假装要走；否则拉锯。
- 【客人观察】Lv4 性格词：某维度偏离 0.5 达 0.15 以上才说，最多 3 个，按偏离大小排序。

## 2. 预期值向量

```
Expectation
  color:    颜色（色相表上的一个值）
  material: 材质
  pattern:  图案
  weight:   {color, material, pattern} 三个维度的重要性权重，和为 1
  priority: 顺序（先找这个，没有再找下一个）
```

- 每位客人带 **1–3 个**预期值（数量由挑剔度派生，§1.4），按 `priority` 排序。生成来源：第一条从趋势向量 + 个人偏差采样（现有 `preference`），后面几条在第一条附近做变体（换颜色或换图案），偶尔完全独立。
- **货与预期值的差值** `d`：三个维度各算一个 0–1 的距离再加权。颜色用色相 / 明度表上的距离；图案和材质用相似度表（图案相似度表与 03 §3 的认错概率共用一张）。`d = w_c·d_color + w_m·d_material + w_p·d_pattern`。
- **容差** `tol` = 派生的 `tolerance` + 每次来摊的随机偏移（±0.05）。**占位待办**：加入客人经济情况字段，手头紧的容差大（有就行）、手头松的容差小。
- **客人在外面看到的不是真货**：边缘颜色看得全，图案只看到边缘露出的部分（与玩家翻看同一套"部分可见 → 可能认错"逻辑），材质从外面看不出，只能按外观猜。挑选阶段用**感知属性**算 `d`；真属性在议价的策略环节才起作用（§3.4）。这让"把好货摆在显眼位置"和"客人看走眼"都成为真实现象。
- **初始成交可能性**：`P0 = clamp(1 − (d / tol)^1.5, 0.25, 0.90)`。`d = 0` 的货 0.9 起步，刚擦着容差边进来的 0.25 起步。
- **当前实现值（PR #12，`core/sim/attr_distance.gd`，表在 `data/scarf_attributes.json`）**：
  - 颜色：每种颜色有 `hue`（色相角）、`light`（明度 0–1）、`chroma`（彩度 0–1）。`d_color = 0.6·(Δhue/180)·min(chroma_a, chroma_b) + 0.7·|Δlight| + 0.4·|Δchroma|`，夹到 0–1；黑白灰彩度为 0，不计色相差。例：红与驼约 0.23，红与藏青约 0.49。
  - 图案、材质相似度表：键写成 `a|b`（不分顺序），未列出的组合相似度为 0。图案：格纹|条纹 0.6，碎花|波点 0.5，条纹|波点 0.3，纯色|波点 0.25……材质：真丝|冰丝 0.7，羊毛|羊绒 0.7，冰丝|薄纱 0.55，羊毛|针织 0.55……`d_pattern = 1 − sim`，`d_material = 1 − sim`。
  - 翻看认错（03 §3）改为同一张图案表驱动：认成图案 q 的概率 `= 0.32·sim(p, q)²`，纯色合计约 2%，格纹约 14%（多认成条纹），碎花约 10%。

## 3. 流程

### 3.1 经过与停留

**摊位热闹程度** `H ∈ [0.1, 1]`：`H = clamp(0.1 + 0.3·当前在摊前的客人数 + 0.03·摊上货物份数, 0.1, 1)`。空摊 0.1；两个客人加二十份货就接近 0.8。

**热闹偏好** `c ∈ [−1, 1]`（派生自外向，§1.4），停留倍率不是布尔分支而是一条连续曲线：

```
m_crowd(c, H) = (1 + c)/2 · H  +  (1 − c)/2 · (1.1 − H)
```
- `c = 1`（最爱热闹）：倍率就是 `H`，空摊 0.1、满摊 1，与"空摊 0.1、要补到 1 需要 10 倍"的直觉一致；
- `c = −1`（最爱清净）：倍率 `1.1 − H`，空摊 1、满摊 0.1；
- `c = 0`：常数 0.55，无所谓。

```
stay_p = clamp( base · m_crowd(c, H) · 吆喝修正 · 展示度 · 偏好匹配（第一条预期值与摊上最接近货的 1 − d/tol，夹到 0.3..1）, 0, 1 )
```

**保底机制（生成不是全随机）**：开一个"合拍客人计时器"，间隔 `T = T0 / (1 + k·摊上货物份数)`（初值 `T0 = 90 秒，k = 0.08`：摆 10 份货约 50 秒一个，摆 25 份约 30 秒一个）。计时器到点时，下一位过路客不随机生成，而是：从原型里抽一个，把 `c` 设成让 `m_crowd(c, H) ≥ 0.9` 的值，第一条预期值直接从摊上**实际摆着的货**里抽一份并落在容差内。其余过路客照常随机。这样货摆得越多、越容易等到合拍的人，玩家能感觉到"摆满点有用"，但看不出保底的存在。

### 3.2 停留后挑选

- 客人按 `priority` 顺序拿第 1 条预期值扫一遍摊上**可见**的货（堆顶最可见，越往下越容易被忽略，沿用 `1 − 0.1·上方份数`），有 `d ≤ tol` 的就选差值最小那份；一份都没有就换第 2 条，依次到最后一条。全都没有 → "看了看走了"，计入 `no_match` 统计（结算页告诉玩家"有 N 位客人没找到想要的"，【客人观察】Lv1 可在当场看到他想要什么）。
- **挑选是有时长的**：每看一份货花 `0.4 + 1.6·(1 − browse_speed)` 秒，所以从容又挑剔的人会在摊前站很久，急躁的两眼扫完就走。站多久本身就是玩家能读到的信息。
- 选中后得到 `P0`（§2），进入问价。

### 3.3 问价

主动 / 被动按 `initiative` 掷一次。

- **主动**：客人直接报价 `O = R · anchor`，`anchor` 由诚实度决定：诚实 `candor ≥ 0.6` 时 0.85–1.0（报的差不多就是心理价），算计时 0.55–0.75（故意压低）。`R` 为心理价（现有 `reserve_price`，含预算、匹配修正、同次购物上下文 01 §4.3）。
- **被动**："多少钱？"。此时玩家的**第一口价** `Q` 很关键：`Δ = (Q − R)/R`，`P += −1.2·max(0, Δ) + 0.4·max(0, −Δ)`。报高两成直接掉 0.24；报在心理价以下有小幅加成（给的是好感，不是白送）。
- **`P ≤ 0` 的瞬间客人离场**（"太贵了"），计入 `scared_off` 统计。
- **占位待办**：报价落点用心动 / 心碎小动画提示玩家（心动 = `P` 升，心碎 = `P` 降），动画强度随【客人观察】等级更精确。

### 3.4 拉扯

**耐心是次数** `patience_n`（隐藏，派生，标准 5–7，§1.4）。消耗规则：玩家每用一次策略 −1，玩家每报一次价 −1，客人每还一次价 −1。所以一轮"玩家出手 + 客人回应"消耗 2，5–7 次 ≈ 三轮，符合预期。口才 Lv5：玩家每第三次动作不扣耐心。

**三个策略**，各对应预期值的一个维度，作用是**缩小该维度上货与预期的差值**，从而抬高 `P`：

| 策略 | 维度 | 台词方向 |
|---|---|---|
| 【保证品质】 | 材质 | "这是真羊毛，摸摸看" |
| 【宣传颜色】 | 颜色 | "这颜色衬您，今年就流行这个" |
| 【展现图案】 | 图案 | "您看这花纹展开是这样的" |

```
成功率 s = 0.5 + 0.08·口才等级 − 0.3·fastidious + truth_bonus
成功：该维度差值 ×(1 − r)，r = 0.5·(1 − 0.5·fastidious)；重算 d → P = P0' 并保留之前报价造成的增减
失败：P −0.05
```
- `truth_bonus`：策略说的是**真话还是吹嘘**由真相层决定。客人在挑选阶段用的是感知属性，如果真属性在这个维度上**比他看到的更接近**预期（图案只露了一角、材质看不出来），那么这是真话，`truth_bonus = +0.3`，成功后差值直接按真属性重算（往往一步到位）；如果真属性**更远**（玩家在吹），`truth_bonus = −0.2`，并且失败时被精算的客人识破的概率为 `shrewd`，识破 → `P −0.15`、`rapport −0.2`、台词变冷。**这要求玩家先知道自己摊上这份货到底是什么**（翻看、记忆），策略才用得准：信息不透明再次落到玩法里。
- 同一维度对同一份货只能用一次策略；三个维度最多三次，正好是一个标准客人耐心的一半。
- 口才 Lv2：失败扣 `P −0.03` 而非 −0.05；Lv4"放宽条件"改为挑选阶段 `tol +0.1`（更多客人会开口）。

**客人还价**：每次还价把 `O` 向浮动心理价靠一步：`O ← O + (R_float − O)·(0.35 + 0.3·agreeable)`，并按 `haggle_strategy` 配台词（直接要折扣 / 装作要走 / 拉锯）。

**成交条件**（满足任一）：
1. 玩家当前报价 `Q` 之下 `P ≥ 1.0` → 按 `Q` 成交（他被说服了，接受你的价）；
2. `Q ≤ R_float`，其中 **`R_float = R · P · (1 + ρ·rapport) · (1 − δ·g(basket_count))`**（01 §4.3 的好感与件数修正叠在用户给的 `心理价 × 成交可能性` 上）→ 按 `Q` 成交；
3. 玩家点"就按他说的卖" → 按 `O` 成交（随时可以）。

**耐心归零**：按 `temper` 掷一次：中 → 嘟囔一句难听的（`rapport −0.3`，并让摊前其他客人的 `P −0.05`，这是"闹场"），不中 → 默默走。然后离开，常客 `return_probability −0.05`。

### 3.5 再次浏览

交付完成后（01 §6.4），掷一次是否再逛：

```
p_again = clamp(P_final, 0, 1) · (0.4 + 0.4·sociable + 0.2·intent − 0.3·hesitation) · [剩余预期值 > 0] · f_budget(剩余预算)
```
`P_final` 是成交那一刻的 `P`（被说服到 1.2 的比刚够着 0.6 的更愿意继续）。再逛就回到 §3.2，用**剩余的**预期值重新挑，同次购物上下文（好感、件数、预算）沿用 01 §4.3。**占位**：性格修正公式之后再调。

### 3.6 等待与自取

成交后进入等货（01 §6.4 的时长与递错规则不变）。**等待结束时**：
- 货还**摆在摊上**（玩家没动它）：按 `self_serve` 掷一次。中 → 客人**自己上手拿**，走 03 §5 的 NPC 取货（会按他的马虎和耐心决定拆顶还是硬抽，可能塌一地），拿到后按**谈好的价**付钱走人；**占位**：精算客人自取时有概率只付自己最后一次还价 `O`。不中 → 转身离开，计入 `lost_after_deal`。
- 货在**玩家手上**（拿起来了却没点客人）或已不在摊上：客人拿不到，直接离开，`rapport −0.3`、常客 `return_probability −0.1`。（实现：只有货**不在摊上**时才扣这两项；货在摊上且自取掷中 → 自己拿走成交。）
- 两种离开都算"谈成没拿到货"的流失。

### 3.7 讲价 / 逛摊的实现值（PR #13）

- `BASE_STAY_P = 0.6`；材质外观猜错 `MATERIAL_GUESS_SCALE = 0.5`（与图案认错同形：`scale × 相似度²`）。客人看到的货（认错图案 / 猜错材质）按**每份货**缓存，同一人反复看不会重掷。
- 第一口价：`P += −1.2·max(0, Δ) + 0.4·max(0, −Δ)`；之后再报高于 `R` 的价：`P −= 0.3·Δ`。
- 说服成功率 `s = 0.5 + 0.08·口才 − 0.3·fastidious + 真话 0.3 / 吹嘘 −0.2`；失败扣 `P` 0.05（口才 Lv2 起 0.03）；吹嘘再按 `shrewd` 掷一次被识破：额外 `P −0.15`、`rapport −0.2`。
- **客人还价只往上走**：心理价跌到他已出价以下时咬住不动，不往回缩（实测不加这条会出现"越谈他出价越低"）。
- 「一起买」谈不拢：额外扣 1 次耐心、`P −0.05`。
- 交货成功后再逛：耐心恢复一半。
- 嘟囔难听话：摊前其他客人 `P −0.05`。
