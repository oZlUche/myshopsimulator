## 0. 现状盘点与本文档的边界

**已有的**（01 §4.2，`core/sim/economy_state.gd` 已实现）：
- 双循环 `E(t) = Base(year) + C(t) + Season(t)`：年度随机调整的 `Base`（只看历年 Δ）、最近 ≤36 旬指数衰减加权的 `C`（λ = 0.88）、季节材质基线（换季各 1 旬插值）。
- `Base` 里已有四个参数：`consumption_level`（消费水平）、`material_bias`（材质偏好偏移）、`wholesale_credit_risk`（批发拖账倾向）、`loan_rate_base`（基准利率）。但目前**只有 `consumption_level` 和材质偏好真正在用**（客人预算倍率、进货目录权重）。
- 时尚趋势 `Trend`（颜色、图案）独立于经济，另有随机游走 + 排期跳变。

**没有的**（v0.1 时）：经济状态到**各项价格**的传导公式。进货价当时是 `base_cost × U(1.05, 1.3)`，与经济无关；运费、房租、工资、利率、税务都还没有数值定义。

**v0.2 进度**：阶段 0 已实现（PR #20，`core/sim/economy_state.gd`）：π、M_m、本地店进货价、客人预算与客流、名义标价全部接入；r、F、κ、ρ_target 每旬已在算但还没接到任何付款（运费、利息、房租、拖账分别等阶段 1 的对应功能）。各节"当前实现值"标注了与初稿的偏差。

本文档补的就是这一层：**少数几个宏观状态 → 一组确定的传导公式 → 每一项玩家会付或会收的钱**。原则：
1. **一个主驱动**：所有周期效应都从景气指数 `G` 出发，玩家感受到的是"同一个大势"在不同地方的回声，而不是七八个互不相关的随机数。
2. **成本黏、需求敏**：衰退伤害商家主要通过**需求侧**（客人少、心理价低），成本只缓慢跟随。这是现实，也让周期有可读的"剧本"：先是客人变少，几个月后房租才降。
3. **名义价格长期上涨**：有一个缓慢的物价水平 `π`，所有价格都是实际值 × `π`。这样玩了三年回头看，当年 30 块的围巾卖 36 是正常的；手里躺着的现金在悄悄缩水。
4. **全部隐藏**：玩家只看到进货目录、客流、成交价这些结果，不看到 `G`。后期技能【经济嗅觉】（01 §4.2 预留）做带噪预报。

## 0.1 借用的经济学原理（不求严谨，够跑就行）

用户要求：可以直接用现实里的经济学公式与理论，整体能跑即可。本文档每条公式对应的原理如下，方便以后查书调参：

| 公式 | 借的原理 | 怎么简化 |
|---|---|---|
| `G` 双循环（01 §4.2） | 商业周期 + 均值回归（AR 过程） | 年度 Δ 做一阶自回归带均值回归，不建 IS-LM |
| `π` 通胀 §1.2 | **菲利普斯曲线**（景气高 → 通胀高）+ 通胀惯性 | 用 `g` 代替产出缺口，线性 |
| `r` 利率 §1.3 | **泰勒规则**（利率 = 中性利率 + a·通胀缺口 + b·产出缺口） | 系数 0.5 / 0.08，央行是个函数不是实体 |
| 进货价 §3.1 | **需求拉动 vs 成本推动**；供给冲击（AR(1) 均值回归） | 需求拉动弹性 0.25，成本冲击按材质独立 |
| 消费能力 §3.3 | **需求的收入弹性**（围巾是弹性 > 1 的非必需品） | 弹性取 1.2 |
| 房租 §1.5 | **黏性价格 / 菜单成本**（合同期内不调） | 只在续约时跳到目标值 |
| 工资 §3.4 | 劳动市场紧张度 → 工资（简化的**工资菲利普斯曲线**） | 弹性 0.3 |
| 利息与额度 §3.5 | 风险溢价 = f(信用) | 线性 spread |
| 拖账 §1.7 | 衰退期违约率上升（**信用周期**） | 线性放大 |
| 税务 §3.6 | 增值税 / 所得税的起征点与累进 | 三档，政策年度随机微调 |
| 名义 vs 实际 | **费雪关系**：名义 = 实际 × 物价 | 所有表存实际值，显示时乘 π |

### 1.1 景气 G

沿用 01 §4.2 与 `economy_state.gd`：`G(t) = Base_year + C(t)`，`Base` 每 36 旬随机调整并带均值回归，`C` 为最近 ≤36 旬观测的指数衰减加权。`G` 夹在 `[0.6, 1.6]`（PR #20 已把下限从 0.3 提到 0.6）。

**v0.2 改动：`C` 必须去中心**。实现后实测：`C` 只用 `price_ratio = 成交价/(base_price·π) − 1`，而玩家正常成交价本来就低于标价（议价让利），所以 `C` 长期为负，`G` 漂到约 0.92；再经 `S = G^1.2` 压低客人预算 → 成交价更低 → `C` 更负，自反馈放大约 2.5 倍，三年后 `G` 落在 0.68–0.82。原因是"绝对成交价比"衡量的是**玩家的定价习惯**而不是**景气的变化**。

改法：每一维观测都只看**相对自己最近 ≤36 旬均值的偏离**，再按 §1.1 原计划加入成交量与客流：
```
对每一维 x ∈ {price_ratio, sales, traffic}：
  x̄    = 窗口内（≤36 旬）等权均值
  dev_x = (x − x̄) / scale_x
  scale_price   = 0.10                    （成交价比动 10 个百分点算一个"显著单位"）
  scale_sales   = 0.3 · max(x̄_sales, 1)   （成交量相对自己均值动 30%）
  scale_traffic = 0.3 · max(x̄_traffic, 1)
dev(t) = 0.5·dev_price + 0.3·dev_sales + 0.2·dev_traffic
C(t)   = clamp( 0.1 · Σ_i λ^i · dev(t−i) / Σ_i λ^i ,  −0.15, 0.15 )      λ = 0.88（不变）
观测不足 4 旬时 C = 0
```
- 这样 `Base = 1.0` 时 `G` 长期均值就是 1.0：玩家卖得便宜或贵只改变 `x̄`，不改变 `G`；`C` 只捕捉"最近比自己过去好 / 差"的**动量**，这才是连续循环该表达的东西。
- 自反馈被切断：`S` 压低预算 → 成交价比下降 → 几旬后 `x̄` 跟着下降 → `dev` 回零。放大倍数从 2.5 回到约 1.0–1.2（只剩短期动量）。
- `continuous_gain` 不再是存档里的可调量：老存档里存的 0.5 直接忽略，用上面的常数 0.1；`lambda` 同理可留在存档但以常量为准。不升 schema。
- 调参目标：连续 6 旬成交价比高于自己均值 10 个百分点、成交量高 30%、客流高 30%（三维同时显著），`C ≈ +0.1`；单一维显著约 +0.03 到 +0.05。`C` 的夹限 ±0.15 保证年度 `Base` 仍是主旋律。

**当前实现值（PR #24）与三年验证**：按上式实现（`LAMBDA 0.88`、`C_GAIN 0.1`、`C_MAX 0.15`、`C_MIN_OBS 4` 为常量；某维缺失按均值处理）。AutoSeller 4 个种子各 108 旬共 432 样本：`G` 均值 0.993、σ 0.059、范围 0.880–1.108（p10 0.901、p90 1.089）；`C` 均值 −0.0009、范围 ±0.016，即 `G` 基本就是年度 `Base`，漂移消失。三年 `π` 1.066–1.115（年化 2.2%–3.7%）。

但"30 旬平稳后连续 6 旬三维各高 1 个显著单位"实测 `C = +0.037`，远小于目标 +0.1。两个原因：均值把这 6 旬也算进去了（偏离摊薄约 17%）；λ = 0.88 下最近 6 旬只占权重的约 54%。**v0.3 改法**：
```
x̄   = 不含最近 6 旬的窗口均值（旬 7..36 的等权均值）；这部分不足 4 条时 C = 0
C   = clamp( 0.2 · Σ λ^i · dev(t−i) / Σ λ^i , −0.15, 0.15 )           增益 0.1 → 0.2
```
预期：同一场景 `C ≈ +0.11`；好转持续 36 旬以上则基线跟上、`C` 回零（这正是"动量"该有的性质）；全窗口同向最大也只到夹限 0.15。开局前 10 旬 `C = 0`。

**当前实现值（PR #27）与复测**：按上式实现，常量 `C_RECENT = 6`、`C_GAIN = 0.2`，基线不足 4 旬时 `C = 0`，不升 schema。场景"30 旬平稳，之后每旬同样偏离"，`C` 在偏离开始后第 6 / 12 / 18 / 24 / 30 / 36 旬的值：

| 偏离 | 6 | 12 | 18 | 24 | 30 | 36 |
|---|---|---|---|---|---|---|
| 三维各 +1 单位 | +0.108 | **+0.115** | +0.096 | +0.067 | +0.034 | 0 |
| 只有价比 +1 | +0.054 | +0.059 | +0.051 | +0.036 | +0.019 | 0 |
| 只有成交量 +1 | +0.032 | +0.034 | +0.027 | +0.018 | +0.009 | 0 |
| 只有客流 +1 | +0.022 | +0.022 | +0.018 | +0.012 | +0.006 | 0 |
| 三维各 −1 单位 | −0.108 | −0.122 | −0.109 | −0.081 | −0.044 | 0 |

- 峰值在第 12 旬左右而不是第 6 旬（第 7–12 旬基线里才开始混进好转的旬），满 36 旬准确回零，正是想要的动量形状。
- 单维显著的实测为价比 ≈ +0.055、成交量 ≈ +0.03、客流 ≈ +0.02（上文"+0.03 到 +0.05"按此修正为 **+0.02 到 +0.055**），与权重 0.5 / 0.3 / 0.2 成比例。
- AutoSeller 4 种子 × 108 旬（432 样本）：`G` 均值 1.018、σ 0.068、范围 0.876–1.234（p10 0.944、p90 1.090）；`C` 均值 +0.0009、范围 −0.061 到 +0.090、|C| 中位 0.012、p90 0.034，没碰到 ±0.15 夹限，没有漂移。`G` 均值比 PR #24 的 0.993 高是随机数消耗顺序改变后年度 `Base` 走了别的路径（一个种子 `Base` 末值 1.231），不是 `C` 的系统偏移。各种子末年 `π` 1.076–1.132。

**传导弹性**（下文各公式都用它）：把 `g = G − 1` 当作偏离度，各项对 `g` 的敏感度写成弹性 `e`，含义是"景气高一成，该项涨几成"。

### 1.2 物价水平 π

```
infl(t) = i0 + e_i · g(t−1) + N(0, σ_i)        每旬通胀率
π(t)    = π(t−1) · (1 + infl(t))
```
- `i0 = 0.0008`（约年化 3%），`e_i = 0.004`（景气 1.2 时年化约 5.9%，景气 0.8 时约 0.1%），`σ_i = 0.0005`。通胀率夹在 `[−0.001, 0.004]` / 旬，即年化 `[−3.5%, +15%]`，正常年份不会碰到边。
- **所有名义价格 = 实际值 × π**。`base_cost`、`base_price`、租金表、工资表里写的都是**实际值**（以第 1 旬为基准），显示给玩家时乘 `π`。
- 存档只存 `π(t)`，不需要存历史。
- **当前实现值（PR #20）**：公式与系数同上，`π` 在**旬末**更新、用刚结束那一旬的 `g(t−1)`；另存 `last_inflation` 供 §1.3 年化。

### 1.3 基准利率 r

```
r(t) = clamp( r0 + e_r · g(t) + 0.5 · (infl_年化(t) − 0.03), 0.02, 0.12 )
```
`r0 = 0.05`（即现有 `loan_rate_base`），`e_r = 0.08`。景气热、通胀高则加息。每 3 旬结算日按当时的 `r` 计一期利息（§3.5）。
- **当前实现值（PR #20）**：`infl_年化 = (1 + infl)^36 − 1`；`r` 已由 `effective().interest_rate` 每旬算出，**尚未接到任何利息结算**（等阶段 1 借贷）。

### 1.4 运力指数 F

```
F(t) = F_rw(t) · (1 + e_F · g(t)) · season_F(t)
F_rw(t) = 1 + 0.85 · (F_rw(t−1) − 1) + N(0, 0.03)          均值回归随机游走
season_F = 冬 1.08，春秋 1.0，夏 0.97（雨季 / 高温另算，暂不做）
```
`e_F = 0.3`：运费对景气比进货价敏感（运力紧张），这是玩家在旺季最先感到的成本。
- **当前实现值（PR #20）**：`F_rw` 夹到 `[0.7, 1.4]`；`effective().freight_index` 每旬算出，**尚未接到运费**（阶段 1）。

### 1.5 租金指数 ρ（黏性）

```
ρ_target(t) = π(t) · (1 + e_ρ · ḡ_12)                        ḡ_12 = 最近 12 旬 g 的均值
ρ_contract   在签约 / 续约那一旬 = ρ_target；合同期内不变
```
`e_ρ = 0.25`。**当前实现值（PR #20 / #23）**：`rent_index_target` 每旬按上式算（`g_history` 存最近 12 旬 g）；店面与仓库已带 `rent_contract {rent_per_m2_nominal = 实际单价 × ρ_target, start_period, end_period}`，签约旬定价、36 旬一签（07 §4），**扣租金尚未实现**（阶段 1）。店铺与仓库合同期默认 **36 旬**，摆摊阶段无租金。续约时房东按 `ρ_target` 开价，玩家可用口才议价（±5%）或搬家。衰退期**租金不会立刻降**，这是现实里压垮小店的东西，也是"提前存钱"的理由。

### 1.6 材质供给冲击 M_m

每种材质一个独立的均值回归随机游走：
```
M_m(t) = 1 + 0.9 · (M_m(t−1) − 1) + N(0, 0.025)，夹到 [0.7, 1.5]
```
偶发事件（概率 2% / 旬）给某一材质一次 ±0.15 的跳变并在 6 旬内衰减（"今年羊绒原料涨了"）。它只影响进货价，不影响客人心理价，所以是**毛利的真正波动来源**。
- **当前实现值（PR #20）**：与上式一致（AR 0.9、σ 0.025、夹 [0.7, 1.5]；事件 2%/旬、随机材质、±0.15 等概率、6 旬线性衰减到 0，叠加后再夹）。`material_shock` 存随机游走部分，`material_events` 存事件列表。

### 1.7 拖账倾向 κ

```
κ(t) = κ0 · (1 + 1.5 · max(0, −g(t)))
```
`κ0 = wholesale_credit_risk`（0.1）。衰退时批发客人更容易拖账；只在 04 文档的"批发拖账"开关打开时生效。
- **当前实现值（PR #20）**：`effective().credit_risk` 已算，批发拖账逻辑未接（阶段 1）。

### 1.8 节拍层 B(t)：季节、节日、天气与口碑（2026-10-22）

**定位**：景气 `G` 是慢变量、全市场、隐藏的；节拍 `B` 是**快变量、公开的日历**：围巾冬旺夏淡、年关前抢购、集市日人多、突然降温大家都来买。它单独一层，**只乘在过路客密度和购物意向上**，不进 `G`、不进预算、不进任何价格；`C` 项的客流观测先除掉 `B`（§1.1），免得年年都有的节拍被当成动量。年均值归一到 1.0，所以它不改变经济的长期水平，只改变一年里"忙和闲"的分布。

**日历对应**（`Clock`）：旬号 `p` 从 1 起，3 旬 = 1 月，9 旬 = 1 季，36 旬 = 1 年；第 1 年 1 月上旬开局；**1–3 月春、4–6 月夏、7–9 月秋、10–12 月冬**；旬在年内的序号 `q = (p − 1) mod 36 + 1`，月份 `m = ceil(q / 3)`。年关 = 12 月下旬到次年 1 月上旬。

```
B(t) = clamp( Season_d(q) · Cal(q) · Weather(t) / Z ,  0.6, 1.6 )
```
| 项 | 公式 / 表 | 说明 |
|---|---|---|
| **季节需求** `Season_d` | `1 + 0.35 · cos(2π · (q − 32) / 36)` | 峰值 11 月中（q = 32）1.35，谷值 5 月中（q = 14）0.65；余弦在一年里均值恰为 1 |
| **日历事件** `Cal` | 下表各事件在其旬区间内的倍率相乘，区间外为 1 | 固定、公开，规划页日历上提前看得到 |
| **突发天气** `Weather` | 随机事件，带衰减；详见下表 | 玩家看不到预告（【经济嗅觉】/ 新闻句可泄露） |
| **归一化** `Z` | `Season_d · Cal` 在一年 36 旬上的均值（常数，开局算一次） | 保证固定部分年均 = 1.0；天气项正负大致相抵，不归一 |

|---|---|---|---|

同类事件不叠加（已有未衰减完的就不再触发）；不同类可叠加后再夹限。期望值约 0.99–1.01，不另归一。

**开店后的口碑 `W`**（阶段 1，占位）：只加自己店的客流，不影响 `G` 和别人。
```
s_t = (满意离开人数 − 不满离开人数) / 来访人数          满意 = 成交或平静逛完；不满 = 耐心归零、被递错、再问惹烦、等货自取失败
W(t) = 0.9 · W(t−1) + 0.1 · s_t，夹到 [−1, 1]
自家客流 × (1 + 0.3 · W)                               范围 0.7–1.3；摆摊阶段没有 W（吆喝顶替）
```
`W` 与借贷用的**信誉分**（01 §6.7）是两回事：信誉分是对银行 / 批发商的，`W` 是街坊口碑。

**应用**（§3.3 一起看）：
```
过路客 / 进店密度  density × (0.7 + 0.3·G) × B(t) × (1 + 0.3·W)
购物意向          intent + 0.1·g + ΔI_cal + ΔI_weather（夹到 0.05..1）
C 的客流观测      traffic_obs = 实际客流 / (B(t) · (1 + 0.3·W))
```
- **玩家看得到**：规划页日历标出本月和下月的固定事件（"下旬集市"、"再过 3 旬年关"），这是进货和排班的依据；天气事件只在发生当旬提示（"今天突然降温"），【经济嗅觉】Lv2 起提前一旬给带噪预告。
- **三年验证目标**：`B` 的固定部分年均 = 1.000（归一保证），含天气的年均 0.98–1.02；总客流系数 `(0.7 + 0.3·G) · B` 的范围约 0.56–1.70（`G` 0.88–1.23 时），年关三旬是全年客流峰，5 月中是谷；AutoSeller 跑三年时 `C` 均值仍应 ≈ 0（客流观测已除掉 `B`）。
- **数据**：固定部分全由 `p` 算出，不存；`EconomyState.rhythm_events: [{kind, start, duration, traffic_mult, intent_add}]` 同 `material_events` 的形式，默认 `[]`，老存档读入为空，不升 schema。`effective(period)` 增补返回 `rhythm_mult`（B）、`rhythm_intent_add`、`calendar_events: [事件名]`。

## 3. 传导公式：每一项钱怎么算

### 3.1 进货价

```
进货单价 = base_cost · π · M_m · (1 + e_s · g) · S_mat(t) · supplier_level · pack_mult · case_disc · haggle
```
| 因子 | 含义 | 取值 |
|---|---|---|
| `base_cost` | 该 SKU 的实际成本基准（`scarf_attributes.json` 已有） | 表 |
| `π` | 物价水平 | §1.2 |
| `M_m` | 该材质的供给冲击 | §1.6 |
| `e_s · g` | 需求拉动：景气好批发商也抬价，但**弹性低** | `e_s = 0.25`（景气 1.2 → +5%） |
| `S_mat` | 季节压力：当季材质 +8%，反季清仓 −10%，按季节基线占比算 | **v0.2**：`1 + 0.1·(share / 均值 share − 1)`，夹到 [0.9, 1.08]（见下） |
| `supplier_level` | 渠道：摆摊阶段本地店 `U(1.05, 1.3)`（现状）；开店后批发市场 0.85–1.0、托运部直供 0.8–0.95 | 01 §6.1 |
| `pack_mult` | 包型（07 §1.1）：散货按条 1.0；**单色包 0.92；混色包 0.85**（厂价 = `base_cost · π · M_m · (1 + e_s·g) · S_mat`） | 以 07 为准 |
| `case_disc` | 整箱（10 包）再折 | 待开店进货文档定，占位 1.0 |
| `haggle` | 与老板议价（口才） | 0.92–1.0 |

**客人心理价不含 `M_m` 和 `S_mat`**（§3.3），所以原料涨价、反季清仓直接改变毛利：这是进货决策的核心信息。

**v0.2：`S_mat` 的公式改动**。v0.1 写的 `1 + 0.3·(share − 均值 share)` 在 7 种材质下（均值占比 1/7 ≈ 0.143）实际幅度只有 0.96–1.077，反季材质到不了 −10%。改为按**占比 / 平均占比**（`share · 材质数`）算，系数 0.1：

```
S_mat = clamp( 1 + 0.1 · (share_m(t) / mean_share − 1), 0.9, 1.08 )     mean_share = 1 / 材质数
```
按 `scarf_attributes.json` 的季节基线（换季各 1 旬插值不变）得到：

| 占比 share | 例子 | S_mat |
|---|---|---|
| 0.35–0.40 | 春 真丝 / 棉麻，夏 冰丝 / 雪纺，秋 羊毛，冬 羊绒 / 针织 | 1.08（夹限） |
| 0.30 | 秋 羊绒 | 1.08（夹限） |
| 0.20 | 冬 羊毛 | 1.04 |
| 0.15 | 春 雪纺，夏 真丝 | 1.005 |
| 0.10–0.12 | 秋 针织 / 棉麻 | 0.97–0.98 |
| 0.08 | 夏 棉麻，秋 真丝 | 0.956 |
| 0.05 | 春 冰丝 / 羊毛 | 0.935 |
| ≤ 0.03 | 各季反季材质 | 0.90–0.92 |

读法：当季主材 +8%，次主材 +4%，过渡材质 ±1%，淡季材质 −4% 到 −10%。不用 0.3 系数的"占比 / 平均占比"是因为那样几乎所有材质都贴在两端夹限上，失去过渡档。

- **当前实现值（PR #20）**：本地店进货价 = `base_cost · π · material_cost_mult[m] · U(1.05, 1.3)`，其中 `material_cost_mult[m] = M_m · (1 + 0.25·g) · S_mat`，**四舍五入到 0.5 元**；批发包价 = 厂价 × `pack_mult`，厂价含 `π · material_cost_mult`（07 §1.1）。`S_mat` 已按本节 v0.2 公式实现（PR #24），`share` 取 `effective()` 里含年度材质偏移并归一化后的占比。

### 3.2 运费（开店后）

```
单程运费 = (起步价 + 每公里价 · 距离) · F · 载重系数
起步价 = 15 · π，每公里价 = 1.2 · π · (0.6 + 0.4 · 载重/满载)
```
自己开车（01 §4.6）只付油费：`油费 = 距离 · 0.6 · π · F`，但要花时间和承担破损（驾驶技能）；请托运部付整笔运费。`F` 的波动让"旺季自己开车、淡季叫车"成为策略。

### 3.3 消费能力

```
实际消费能力  S(t) = G(t)^1.2
客人预算倍率  budget_mult = S(t) · π(t) · exp(N(0, 0.18))          （现有 `budget_mult` 改为含 S 与 π）
客人心理价    R = base_price · budget_mult · 匹配修正                （06 §2，不变）
过路客密度    density × (0.7 + 0.3 · G) × B(t) × (1 + 0.3·W)      （B、W 见 §1.8；W 开店后才有）
购物意向      intent + 0.1 · g + 节拍意向加成（夹到 0.05..1）
```
- 弹性 1.2 > 1：消费对景气**放大**反应，是所有传导里最敏感的一条（景气 0.8 → 心理价 −23%、客流 −6%）。配合成本只跟 `e_s = 0.25`，衰退期毛利被挤的感觉就出来了。
- `base_price` 与 `base_cost` 同为实际值，二者之比（`retail_markup = 2.2`）是**不随周期变的**名义毛利空间，周期通过 `S`、`M_m`、`S_mat` 在两边分别挤压。
- **当前实现值（PR #20）**：
  - `budget_mult = G^1.2 · π · budget_noise`，`budget_noise = exp(N(0, 0.18))` 是客人的**个人属性**（常客存 `budget_noise`，每次来店按当旬经济重算 `budget_mult` 与 `intent`；老存档没有 `budget_noise` 时退回存着的 `budget_mult`）。
  - 过路客密度 `×(0.7 + 0.3·G)`，摆摊与店面都用；`intent + 0.1·g` 夹 [0.05, 1]。
  - 观测 `price_ratio = 成交价 / (base_price·π) − 1`，除以 `π` 是为了不让通胀本身反馈进 `C`。
  - **名义价**：新 SKU 默认标价 `round(base_price·π)`，玩家已设的标价**不自动跟涨**（定价是玩家的事，通胀蚕食就是这么来的）；设备买价 `round(表价·π)`，转卖按**当时** `π` 退款；成本价提示（06）`base_cost · 1.175 · π`。

### 3.4 工资（阶段 2）

```
员工期望工资 = wage_base(技能等级) · π · (1 + 0.3 · g)
```
景气好时人难招（期望高、离职快），衰退时好招但客人也少。工资带 `[lo, hi]`（02 §5）按这个数缩放。每 3 旬结算。

### 3.5 借贷与利息

```
一期利息 = 本金余额 · (r(t) + spread(信誉)) / 12            每 3 旬一期 = 1 个月
spread = 0.10 − 0.08 · 信誉分/100，夹到 [0.02, 0.10]
可借额度 = (0.5 + 1.5 · 信誉分/100) · 最近 9 旬平均月净收入 · 3
```
摆摊阶段无信誉也不能借（01 §6.7）。衰退期 `r` 下降但信誉随收入下滑，净效果是"借得起但借不多"。

### 3.6 税务（预留，暂不实现）

设计为 **04 文档的一个可选难度开关【税务】**（默认关），打开后：
```
营业税 / 增值税  每 9 旬：应税销售额 · τ_s，τ_s = 3%；季度销售额 < 起征点（30 000 · π）免税 → 摆摊阶段基本免税
所得税          每 36 旬：max(0, 年利润 − 免征额 60 000 · π) · 分级税率（5% / 10% / 20% 三档）
```
- 政策参数 `T = {τ_s, 起征点, 免征额, 税率档}` 挂在 `Base` 上，年末有 15% 概率调整一档（"今年起征点上调了"），**只由年度 Δ 历史决定**，与 §1 其余状态独立。
- **当前实现值（PR #20）**：`EconomyState.policy = {tax_sales_rate 0.03, tax_threshold 30000, income_exempt 60000, income_brackets [0.05, 0.10, 0.20]}`，只存不算。**v0.2 补分档线**（实际值，显示乘 π）：应税所得（年利润 − 免征额）0–30 000 按 5%，30 000–100 000 按 10%，100 000 以上 20%，超额累进；存为 `income_bracket_limits: [30000, 100000]`（PR #24 已加进 `policy` 默认值）。
- 手动结账（04 可选难度）打开时，税务也要手算；数学能手技能给出核对。
- 账本（认知层）里的利润与真相层不一致时（员工贪腐），**税按账本算**：少报了被查到扣信誉。这是后期的联动点，先占位。
